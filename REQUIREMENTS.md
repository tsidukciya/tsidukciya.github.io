# Задача

Создай с нуля современный профессиональный landing page для книги:

**«Цидукция. Жить, а не выжимать»**
**Автор: Артем Кротов**

Домен проекта:

**https://tsidukciya.ru/**

Главная цель сайта — профессионально представить книгу и автора как авторский проект и привести заинтересованного посетителя к чтению/покупке книги на внешних площадках.

Работай автономно и доведи задачу до production-ready результата.

Порядок работы:

**plan → implementation → build → smoke tests → browser QA → fixes → final report**

Не задавай дополнительные вопросы, если решение можно принять самостоятельно на основании этого ТЗ.

---

# 1. Создание с нуля

Не проводи аудит текущего сайта и не пытайся воспроизводить его существующую архитектуру.

Не нужно:

* анализировать старую структуру сайта;
* мигрировать старые компоненты;
* сохранять старую HTML-структуру;
* переносить старый дизайн;
* сохранять старую информационную архитектуру.

Создай новую структуру landing page исходя из этого ТЗ.

Если в репозитории уже есть проект, необходимые файлы можно заменить или перестроить.

---

# 2. Технологический стек

Использовать:

* **Vite**
* **React**
* современный JavaScript или TypeScript;
* GitHub Pages.

Разрешены разумные npm-зависимости, если они действительно нужны.

Не использовать сложную архитектуру без необходимости.

Цель — быстрый, чистый и поддерживаемый production-ready landing page.
